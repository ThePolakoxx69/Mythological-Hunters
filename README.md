# Mythological Hunters

RPG de exploración y caza de criaturas para Android, con pixel art 2D y combates por turnos, inspirado en mitos y leyendas de Chile.

## Objetivo inicial

Crear una demo offline con movimiento en vista superior, un pequeño pueblo, una ruta de exploración, encuentros, combate por turnos, captura y guardado local.

## Tecnología prevista

- Godot 4.x y GDScript
- Android como plataforma objetivo
- GitHub para control de versiones
- GitHub Actions para automatizar compilaciones cuando el proyecto esté listo

## Estado

En preparación: estructura inicial y prototipo jugable. La APK se considerará disponible solo después de compilarla y probarla en un dispositivo Android.

## Principios del proyecto

- Criaturas, nombres, arte, música e historia originales.
- Inspiración en el folclore y la geografía chilena, distinguiendo relatos documentados de invenciones del juego.
- Juego individual y jugable sin conexión.
- Desarrollo incremental: cada hito debe funcionar antes de ampliar el contenido.
